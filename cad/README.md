# cad

3D-модель Кику кодом на [build123d](https://github.com/gumyr/build123d).

- `kiku_cad/parts.py` — каталог деталей: размеры с источником и пометкой
  `[док]` / `[прод]` / `[оцен]` / `[замер дата]`. Модель берёт размеры только отсюда.
- `kiku_cad/probes/` — пробники для проверки посадок до печати корпуса.
- `build.py` — собрать детали, проверить габарит стола 180 мм и целостность,
  выгрузить STL и STEP в `cad/out/` (в git не хранится), и `plate_probes.3mf` — все пробники на одном столе A1 mini.

## Пробники

| Файл | Что проверяет | Как |
|---|---|---|
| `probe_insert_m3` | отверстие под термовставку M3 (⌀3,6–4,0, глубина 6) и сквозное под винт M3 (3,2 / 3,4) | вплавить вставки, вкрутить винт; выбранный ⌀ записать в `INSERT_M3.hole_d` |
| `probe_pi4` | шаг отверстий Pi 4, саморез M2.5 (⌀2,1–2,4 по углам), зазор по контуру 0,5 | положить Pi, вкрутить винты; выбранный ⌀ — в `M25_TAP` |
| `probe_servo_sts3215` | обойма вокруг корпуса привода, зазор 0,15 и 0,30 на сторону (v2: общая пластина, скругления) | надеть на привод со стороны дна; выбранный зазор — в каталог |

Печать: PLA, слой 0,2, стенки 3, заполнение 20 %, без поддержек, надписью вверх. На бруске точка в подписи не пропечатывается: «36» — это 3,6.
