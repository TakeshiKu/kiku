# Кику

Настольный напарник своими руками: шлем с лицом на экране, 4 оси движения, голос и камера. Raspberry Pi 4, сервоприводы Feetech STS3215, ReSpeaker Lite, экран 2,8" ST7789V, камера IMX219 160°. Корпус печатается на Bambu Lab A1 mini (стол 180×180×180 мм).

## Что здесь

- `cad/` — 3D-модель кодом: параметры деталей, сборка, экспорт в STL/3MF для печати и STEP для доработки в CAD.
- `software/` — программа Кику (появится позже).
- `docs/engineering/bootstrap.md` — как устроен репозиторий и как проверять.

Цели, решения, покупки и состояние — в проектной памяти, не здесь.
