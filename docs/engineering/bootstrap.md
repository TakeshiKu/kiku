# Bootstrap — Кику

## Назначение

Код изделия Кику: 3D-модель корпуса и механики, позже — программа на Raspberry Pi 4. Изделие не зависит от дома владельца: подключение к его серверу, Home Assistant и Hermes описано в проекте Takeshi Ku и `infra`.

## Структура

| Путь | Что | Статус |
|---|---|---|
| `cad/` | модель кодом (build123d или CadQuery — выбор при первой детали) | пусто |
| `cad/out/` | собранные STL/3MF/STEP, в git не хранятся | — |
| `software/` | программа Кику, команда `kiku` (`status`, `logs`, `restart`, `deploy`) | не начато |

## Основной путь

Параметры деталей (документация, замеры штангенциркулем) → компоновка коробками (пересечения, центр тяжести, кабели) → детали с посадками → пробники → печать.

## Ограничения печати

- Стол A1 mini 180×180×180 мм, без AMS: каждый цвет — отдельная деталь.
- Термовставки M3×5×4 (латунь): отверстие ⌀≈4,0 мм, глубина ≥6 мм — уточнить пробником.
- Pi 4 крепится винтами M2.5 в отверстие ⌀≈2,2 мм.

## Проверка

Команд проверки пока нет: появятся с первой деталью — сборка модели без ошибок, проверка пересечений деталей, габарит каждой детали ≤180 мм, экспорт в `cad/out/`.

## Опасные операции

- Питание: блок 12 В на плату сервоприводов напрямую — нельзя, только через понижайку Mini560 на 5 В.
- Деплой на устройство — только командой `kiku deploy`, когда она появится.
